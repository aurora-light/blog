## 技术栈与学习方向

目前主要使用 React、Vue 进行开发，正在结合实际项目学习 Java 后端和全栈开发。下面区分日常使用的技术与正在学习的内容。

### Web 开发

#### 基础与框架

- React（主要技术栈）：组件开发、Hooks、状态管理与交互逻辑组织
- Tailwind CSS、shadcn/ui 与 Radix UI（博客项目实践）：样式组织、组件组合与交互定制

#### Next.js 与服务端渲染

- App Router（博客项目实践）：文件系统路由、动态路由、嵌套布局，以及页面与接口的组织
- Server Components 与 Client Components（博客项目实践与学习）：划分数据读取与交互逻辑，理解 `use client` 边界，减少发送到浏览器的代码
- SSR 服务端渲染（学习中）：理解请求时生成 HTML 的过程，以及实时数据、用户身份与个性化内容对渲染策略的影响
- SSG 静态生成（博客项目实践）：使用 `generateStaticParams` 为文章动态路由提供预渲染参数，理解构建时生成页面的适用场景
- ISR 增量静态再生成（学习方向）：理解部署后更新静态内容的方式，学习按时间与按需重新验证，平衡内容时效性与访问性能
- 水合与渲染边界（学习中）：理解 HTML 展示与客户端事件绑定的过程，排查服务端和客户端输出不一致；区分服务端组件与请求时 SSR，理解客户端组件也可以参与首屏预渲染
- Streaming SSR 与 Suspense（学习方向）：通过 `loading.tsx` 和 Suspense 展示加载状态，理解页面分段返回与渐进展示，区分页面流式渲染和 AI 回复的数据流
- 数据获取与缓存（持续学习）：在服务端组织异步数据读取，理解静态与动态渲染、缓存命中和失效的关系，学习使用 `revalidatePath`、`revalidateTag` 更新缓存
- Route Handlers（博客项目实践）：通过 `app/api` 提供接口，处理请求校验、Redis 限流、异常与流式响应；Server Actions 作为后续表单提交与数据变更的学习方向
- SEO 与资源优化（博客项目实践与学习）：使用 Metadata API、`generateMetadata` 和站点地图组织页面信息，结合 `next/image`、`next/link` 学习图片优化、路由预取与首屏体验优化

#### 工程化与质量

- Vite、webpack、Rollup（有使用经验）：项目构建与打包；持续学习模块解析、产物分析与构建优化
- pnpm、ESLint、Prettier（博客项目实践）：依赖管理、代码检查与统一格式
- TypeScript 类型检查与接口数据校验（博客项目实践）：约束消息结构，使用 Zod 校验流式事件数据
- 性能优化与可访问性（持续学习）：按需加载、渲染开销、键盘操作与交互状态反馈

#### 项目实践

- 个人博客：使用 Next.js、React 与 MDX 展示文章，结合 Contentlayer 组织内容，生成 RSS 与站点地图
- AI 聊天：接入 AI SDK，实现流式回复、Markdown 渲染、思考内容折叠与生成状态展示
- 文章与 PDF 检索：展示多路查询 Trace、匹配来源和 PDF 页码引用，支持从对话跳转到原文
- 前后端协作（结合博客项目学习）：通过 API Route 连接模型服务与检索逻辑，处理参数校验、限流及异常反馈

### Java 与后端生态

- Java 基础（学习中）：面向对象、集合、泛型、异常、注解与反射
- Spring Boot、Spring MVC（学习中）：项目启动、接口开发、依赖注入、参数校验与统一异常处理
- Spring 事务与 AOP（结合项目阅读和学习）：事务边界、自定义注解与切面
- MyBatis、MyBatis-Plus（学习中）：Mapper、实体映射与数据库访问
- Maven（学习中）：依赖管理、多模块工程、编译与打包
- Node.js

### 数据存储与任务调度

- MySQL（学习中）：SQL、数据表设计与事务基础
- Redis（项目实践与学习）：数据类型、TTL、接口限流，以及 Lua 原子操作
- Spring 定时任务、ShedLock（结合项目阅读和学习）：调度、多实例协调与幂等边界
- Nacos（结合项目学习）：配置读取与环境配置管理

### 工程工具与部署

- IntelliJ IDEA（学习中）：Java 项目运行、Maven 同步与断点调试
- Git、Docker（开发与部署工具）
- Nginx（基本使用）
- 单元测试与接口测试（学习中）

### AI 应用与 Agent 开发

- AI 辅助编程与代码校验
- 博客流式聊天、文章/PDF 检索、执行轨迹与动态推荐追问实践
- RAG（项目实践与学习）：构建时索引、AI 查询规划、多路关键词召回、加权 RRF 融合、证据上下文与来源引用；通用能力提取为 search-core 包，后续学习全文分块、向量与混合检索
- Agent 基础（学习中）：理解模型、工具、状态与执行循环，区分固定工作流与模型自主决策
- 工具调用（学习方向）：定义工具参数、执行输入校验、处理工具结果、超时与失败重试
- MCP（学习方向）：通过标准化接口连接外部工具与数据源，理解客户端与服务端的职责
- 记忆与上下文管理（学习方向）：对话历史、状态持久化、摘要压缩与上下文预算
- 工作流编排（学习方向）：任务拆解、条件路由、执行步数限制与人工确认
- Agent 评测与可观测性（学习方向）：固定测试集、工具调用轨迹、任务成功率、耗时和成本记录
- Agent 安全边界（学习方向）：最小权限、提示词注入防护、敏感数据处理与有副作用操作的审批
